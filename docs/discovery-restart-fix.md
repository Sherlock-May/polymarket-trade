# 发现任务隔离及重启恢复

每个开启的币种和周期使用独立发现任务，单次查询最长 20 秒；配置关闭、参数变更和程序退出会取消对应任务。单个市场超时或校验失败不会延误其他市场。

系列返回的每条市场数据单独验证，忽略未通过周期、资产或交易规格校验的条目，继续寻找其他合法未来轮次。如果没有合法结果且有校验失败，仍报告失败，不把无效数据用于下单。

启动时只恢复因“配置关闭或安全停机”关闭的未来轮次，且必须同时满足市场仍开启、尚未开盘、未尝试下单、没有任何订单记录、未结算和非最终状态。已下过单的轮次继续保留原状态，不重新开仓。

简洁日志增加“恢复待预挂”；详细日志增加“市场发现检查”，显示发现的轮次以及是否被关闭，便于区分尚未发现市场与发现后跳过。更新需要正常退出旧进程再重新启动。自动化测试使用模拟数据，服务器实盘及发现接口响应仍需部署后验证。
