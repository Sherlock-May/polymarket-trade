# 撮合通知提前触发止盈

旧路径仅在账户成交状态为 CONFIRMED 时触发止盈，忽略 MATCHED 到最终确认之间可提前检查的时间。

新路径从账户 WebSocket 或 REST 查询中的 MATCHED、MINED、RETRYING 通知提取本程序买单的撮合份额，立即安排独立止盈任务。该份额仅是止盈候选，不写为确认成交或收益。依然必须通过账户可卖余额、授权、最小份额及价格步长检查，卖出数量还要扣除已预留的止盈份额。

余额不足时在独立任务中约每 250 毫秒重新检查，最多持续 30 秒后交回常规管理。间隔不包含网络请求耗时。不同轮次的快速任务互不等待；同轮次通过锁防重复卖出。提交结果未知时继续保留库存预留，不重复签单。

重复交易通知按 trade ID 去重；部分撮合累计处理。FAILED 不计入候选库存，记录异常供对账。确认卖出先于确认买入到达时暂缓收益入账，等待买入确认及 REST 对账。重启后原订单和撮合候选均保留，REST 仍继续核实实际成交。

简洁及成交日志新增“收到撮合通知”和“撮合到止盈提交结果”；详细日志包含撮合时间、推送接收时间、处理时间与查询来源，帮助区分平台通知、排队、余额和提交延迟。未提供的时间不估造。

不保证实际撮合后零延迟挂单成功。撮合可在链上结算前发生；平台余额未可用、推送延迟、连接中断、授权不足、订单拒绝等仍会影响结果。挂单成功不代表止盈成交。
