# 历史订单与实时行情隔离修复

本次修复针对历史止盈单详情为空而反复撤单、主循环处理行情滞后导致预挂持续等待的问题。

- 行情接收任务立即更新盘口；主循环仍处理记录、模拟撮合及价格步长事件。
- 实盘预挂发现盘口缺失或过期时，在 4 秒超时内主动获取完整 REST 快照，并核对资产和交易规格；连接与账户检查仍保留。
- 已结束轮次的对账、撤单和结算放入独立后台任务，不等待这些请求才处理当前轮次。账户成交推送保护路径继续独立运行。
- 撤单响应明确包含订单 ID、但后续订单详情为空时，保留撤单回执；成交核对完成前不结束轮次结算。
- 历史止盈单只有在平台确认市场已最终结算且挂单列表没有该订单时，才结束活动状态。收益仍以成交和结算记录核算，不生成虚假止盈成交。

更新后需要正常退出旧进程再启动。无需清空数据库，也无需修改 `.env`。自动化回归使用模拟接口，未代表服务器上实盘成交及网络延迟已验证。
